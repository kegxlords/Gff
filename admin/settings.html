⚡ OTPay Gateway

Active mode (test/live) + credentials are controlled by server env vars (OTPAY_MODE, OTPAY_*_PAY_URL, OTPAY_*_MERCHANT_ID, OTPAY_*_APP_SECRET). Use the switch below as an instant kill-switch without redeploying.

🔗 Withdrawal Webhook

Every user withdrawal request is POSTed to this URL as JSON (signed with HMAC-SHA256). Use it to forward details to another site, a CRM, Telegram bot, Zapier, or your back-office system.

ℹ️ Notes
• Daily income auto-runs nightly at 23:00 UTC via Vercel cron.
• Fee & bonus changes apply to NEW requests instantly.
• Support links appear on /support and the dashboard welcome popup.
• Withdrawals are open only during the daily window; requests are processed manually by admin.
• Webhook fires on every user withdrawal submission (fire-and-forget — never blocks the user).
• Switching test → live = change OTPAY_MODE env var + redeploy. No code changes, verification stays on.
• Duplicate callbacks, double refunds and double dispatches are all blocked server-side.
